In order to get used to the Machine Learning framework a first task was given to
classify EEG signals of subject executing different tasks. There are 4 different
tasks, Arithmetics, Mirror Images, Stroop, and Relax, and we expect the brain to
have different behaviour during different tasks, so, to be able to classify the
tasks from the EEG signals.

\subsubsection{The dataset}

The dataset \cite{Ghosh2022} includes brain records from 40 subjects performing
different tasks. The EEG cap is a 32-channel Epoc Flex gel
kit from the Emotiv company, and samples at 128 Hzso the data is of shape ().
